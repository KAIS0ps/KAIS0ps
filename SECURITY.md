# Security & Researcher Coordination

## Reporting Issues in `KAIS0ps` Open-Source Crates

If you discover a logic bug, arithmetic edge case, or security issue in any repository under `github.com/KAIS0ps` (such as `vaultguard-rs` or `payguard-rs`), please open a private draft via **GitHub Security Advisories** (`Security` tab -> `Report a vulnerability`) on the affected repository rather than opening a public issue.

## Vendor & Maintainer Verification

Maintainers, `CNA` analysts, and bounty triagers (`Immunefi`, `HackenProof`, `HackerOne`, `Patchstack`, `Wordfence`, `GHSA`) verifying ownership of the `KAIS0ps` handle can confirm identity through:

1. Direct response on the active private submission thread.
2. Signed commit verification or a temporary verification gist under `https://gist.github.com/KAIS0ps` upon request.
